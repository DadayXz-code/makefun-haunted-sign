A one-line sign for the door of a haunted server room: a deadpan warning not to unplug the resident ghost, because it is the only one left who remembers the WiFi password — the kind of line a tired sysadmin tapes to the door at 3am and laughs at on the way past.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
